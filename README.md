# AutoDroid

独立开源的 Android 自动化引擎，目标是提供一套由触发器、条件与动作组成的可扩展自动化模型。项目不复制、不反编译、不引用 MacroDroid 或其他专有应用的代码与资源；功能方向参考公开发布的产品更新说明，实现全部基于公开 Android API。

## 当前模块

- `engine`：纯 JVM 自动化核心，包含触发器事件匹配、规则注册与动作执行模型。
- 已实现的触发器事件：链接打开、端口数据短信、应用启动。
- 已定义的动作模型：通知、发送端口短信、打开 URL。

## 构建

```bash
./gradlew :engine:test
```

项目使用 Kotlin 与 Gradle Wrapper。Windows 下需要 JDK 21。

## 法律与设计边界

本仓库是独立实现。所有名称、接口、数据结构与代码均为原创；不包含 MacroDroid 的 APK、DEX、资源、图标、文案或反编译产物。若要增加与特定商业应用相同的系统能力，请依据 Android 公开文档设计并自行测试。
